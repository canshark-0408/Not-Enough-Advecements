# Not Enough Advencements

A Minecraft Java Edition mod that expands the vanilla advancements system.

## Project Imformation

- Minecraft: 26.2
- Mod ID: nea
- Java: 25
- Loaders: Fabric, Forge, NeoForge

## Project Structure

- common: Shared code a resources
- fabric: Fabric integration
- forge: Forge integration
- neoforge: NeoForge integration
- docs: Project documentaion

## Development

The project aims to minimize unnecessary dependencies and reuse Minecraft's native advancement system wherever possible.
